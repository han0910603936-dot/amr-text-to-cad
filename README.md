# 我的 3D 列印建模工具

用講的就能產生 3D 列印零件。跟 Claude 描述你要的零件，它會寫程式建模、檢查能不能印，再讓你在瀏覽器裡預覽。

## 怎麼用

直接在這個資料夾跟 Claude 說，例如：

> 做一個 RPLIDAR A1 的支架，把光達墊高 80mm，底部用 4 顆 M3 鎖在底盤上，中間留穿線孔。

Claude 會照 `.claude/skills/cad/SKILL.md` 的流程做：建模 → 量尺寸 → 列印檢查 → 截圖自我檢查 → 打開預覽。

改尺寸時講「哪裡、改多少」就好，例如「立板加高 10mm」「孔太緊，放大 0.3mm」。
怎麼寫提示詞可以參考 `研究筆記.md`。

## 資料夾

| 資料夾 | 內容 |
|---|---|
| `src/` | 每個零件的建模程式（一個零件一個檔） |
| `STEP/` | STEP 檔：可以匯入其他 CAD 軟體 |
| `STL/`、`3MF/` | 給切片軟體的列印檔 |
| `lib/cadkit/` | 共用工具：存檔、螺絲孔、列印限制 |
| `tools/` | 列印檢查、截圖、預覽器 |
| `tmp/` | 暫存的檢查檔和截圖，可以隨時刪 |

## 自己執行（不透過 Claude 也可以）

在 PowerShell 裡，從這個資料夾執行：

```bash
C:\Users\jeff2\.cad3d\venv\Scripts\python.exe -X utf8 src\l_bracket.py
```
```bash
C:\Users\jeff2\.cad3d\venv\Scripts\python.exe -X utf8 tools\dfm_check.py STL\l_bracket.stl
```
```bash
C:\Users\jeff2\.cad3d\venv\Scripts\python.exe -X utf8 tools\view.py STEP\l_bracket.step
```

預覽網址：http://127.0.0.1:3939/viewer

預覽器介面是用 `tools\patch_viewer_zh.py` 改成中文的。如果更新了預覽器套件，中文會被蓋掉，再執行一次這個工具就好（加 `--restore` 可以還原成英文）。

## 環境

- Python 3.13 環境放在 `C:\Users\jeff2\.cad3d\`（OneDrive 外面，避免同步上千個檔案）。
- 套件版本記錄在 `requirements.txt`。
- 還沒有印表機：列印限制是一般 FDM 的預設值，買了印表機後要校正 `lib/cadkit/printer.py`。

## 在另一台電腦重建環境（Windows）

在 PowerShell 裡，從專案資料夾依序執行。路徑請換成你自己的。

1. 安裝 uv：
   ```bash
   winget install --id astral-sh.uv --exact
   ```
2. 建立 Python 3.13 環境（放在 OneDrive 外面），並安裝套件：
   ```bash
   uv venv $HOME\.cad3d\venv --python 3.13 --managed-python
   ```
   ```bash
   uv pip install --python $HOME\.cad3d\venv\Scripts\python.exe -r requirements.txt
   ```
   如果是在 Claude 桌面版裡執行而出現路徑錯誤，先設定 `$env:UV_PYTHON_INSTALL_DIR="$HOME\.cad3d\python"` 和 `$env:UV_CACHE_DIR="$HOME\.cad3d\cache"`。
3. 讓環境找得到 `lib/`：在 `$HOME\.cad3d\venv\Lib\site-packages\` 建立 `cad3d_lib.pth`，內容是這個專案 `lib` 資料夾的完整路徑（UTF-8 編碼）。
4. 預覽器改中文：
   ```bash
   $HOME\.cad3d\venv\Scripts\python.exe -X utf8 tools\patch_viewer_zh.py
   ```
5. 測試：執行 `src\l_bracket.py`，`STEP\`、`STL\`、`3MF\` 裡出現 `l_bracket` 就成功了。

## 更新紀錄

### 2026-10-18（夾爪列印檔改成列印方向）
- STL / 3MF 直接存成列印方向、底面在 Z=0，丟進切片軟體就能印；STEP 仍是組裝座標
- 機身：底面朝下（6 個方向裡支撐最少，約 2520 mm²，要開支撐）
- 小齒輪：平放，齒形在層平面上，不用支撐
- 夾爪：齒條背面朝下、齒朝上（只剩約 58 mm² 要支撐），要印 2 個

### 2026-10-18（手腕螺絲改成側面開窗）
- 原本的 Ø8.6 長通道外側牆只有 1.3 mm，改成：底部兩側各開一個朝外的窗口（高 15 mm），M4 螺絲從側面放進去；
  上方只留 Ø5 細孔讓扳手 / 起子伸下來鎖
- 細孔到外牆從 1.3 mm 增加到約 3.1 mm，細孔到伺服口袋約 3.2 mm
- 底板 6 → 4 mm：M4×12 穿過底板 4 + 舵盤 3.2 後，螺帽 3.2 mm 能全部吃到
- 檢查：9 個位置不干涉、12 個孔與窗口 / 細孔確認、最薄 1.4 mm（窗口邊角）

### 2026-10-18（手腕舵盤改成從上往下鎖）
- 原本 M4 要從下往上鎖進機身，但舵盤裝在手腕伺服上，下面被伺服擋住，鎖不到
- 改成從上往下鎖：伺服口袋左右各一條長槽，從機身頂面通到 6 mm 厚的底板；M4×12 穿過底板和舵盤，螺帽在舵盤下面（舵盤軸套空間 7.5 mm）
- 孔位改用舵盤的 (±16, 0)、(±16, −8)，都在伺服口袋兩側
- 安裝順序：舵盤先裝在手腕伺服上 → 夾爪放上去 → 從頂面長槽鎖 4 顆 M4
- 檢查：9 個位置不干涉、12 個孔與通道確認、最薄 1.3 mm

### 2026-10-18（機身後半部改成舵盤外形）
- 後半部（伺服座）從 100 mm 寬縮到 47 mm（= 手腕大舵盤直徑），後面做成跟舵盤一樣的圓弧
- 伺服出口那段圓弧截平，避免口袋側壁和圓弧交會處出現 0.09 mm 的尖薄片（現在最薄 2.2 mm）
- 前面的齒條座維持 100 mm 長
- 機身 105 cm³（原本 152 cm³），估計總重 152 g
- 檢查：9 個位置不干涉、12 個孔確認、重心與手腕舵盤中心差 3.6 mm

### 2026-10-18（小齒輪改成 MATRIX 24 齒大小）
- 小齒輪改成跟 MATRIX 金屬齒輪 24 齒一樣：模數 1、外徑 26、厚 7、中心孔 Ø8
- 小齒輪固定孔同 MATRIX 小舵盤（Micro Servo Horn Wheel 13-0012）的 (±8,0)、(0,±8)，M4 從舵盤背面鎖進小齒輪
- 齒條改模數 1；伺服可轉 360°，小齒輪轉約 322° 全開 135 mm
- 擋邊從 4 mm 加高到 6 mm
- 手腕大舵盤往後移，前緣在機身前端後面 3 mm，後緣跟機身背面切齊
- 機身縮小到 100×50×78 mm，估計總重 177 g（含伺服）
- 檢查：9 個位置不干涉、導引長度最短 59 mm（4.2 倍）、全開越過齒輪中心 14 mm、12 個孔全部確認

### 2026-10-18（齒條座前面打開、加長，齒條加大）
- 拿掉齒條旁邊（前面）的牆，只在外側留 4 mm 擋邊防止齒條往前脫出；小齒輪直接露在前面，安裝更方便
